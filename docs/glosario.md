# Glosario

| Término / abreviatura | Definición | Uso en código |
|---|---|---|
| Grid de ocupación | Rejilla 2D en la que cada celda almacena la probabilidad de estar ocupada | `ogrid` |
| Nube de puntos | Conjunto de ecos del radar entregado en un ciclo (cada 50 ms) | `pcl` |
| Log-odds | Representación logarítmica de la probabilidad, l = ln(p / (1 − p)) | `lo` |
| Eco | Detección individual del radar (distancia, azimut, velocidad radial, RCS) | `echo` |
| Estado seguro | Estado al que pasa el sistema ante un fallo (STD-SAF) | `safe_state` |
